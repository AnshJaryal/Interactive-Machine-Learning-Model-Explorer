ML Classifier Visualizer 🤖📊


An interactive machine learning visualization tool built with Streamlit that lets you explore and compare how different classification algorithms draw decision boundaries on various datasets — all in real time.


Features


6 ML Models — Logistic Regression, SVM, Decision Tree, Random Forest, KNN, and Ridge Regression

3 Datasets — Binary blobs, Multiclass blobs, and the classic Iris dataset

Live decision boundary plotting — see how parameter changes affect model behavior instantly

Tunable hyperparameters — adjust C, kernel, max depth, n_estimators, and more via sidebar sliders 
and dropdowns

Performance metrics — accuracy, precision, recall, F1 score, and a full classification report
